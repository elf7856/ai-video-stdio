Privacy Policy

This policy covers the speech Personal Video Uploader described on our uploader homepage. It describes this local desktop integration, rather than all other Orenix AI services.

Google and YouTube data we access

The uploader requests youtube.upload to upload owner-selected videos and youtube.readonly to check the authorized YouTube channel. The implemented channel check reads the channel ID and display name. Google handles account sign-in; the uploader does not request or store the Google account password.

How data is used

Channel information is used to verify the destination before uploading. The video file, title, description, tags and publication settings chosen for an upload are sent to YouTube. OAuth credentials are used only to authenticate these authorized API operations and refresh access.

Local storage and retention

OAuth client configuration and authorization tokens are stored on the owner’s computer in a private directory with access restricted to the local user. Channel settings and upload receipts are also saved locally. Receipts may contain the video ID, title, link, file checksum and upload status. They remain until the owner removes them. Media remains on the owner’s computer unless uploaded to YouTube or separately shared by the owner.

Sharing and public videos

The uploader sends authorized API requests to Google and YouTube. It does not sell Google user data, use it for advertising, or use it to train general-purpose AI models. This desktop uploader does not forward its OAuth tokens to an Orenix-hosted account database. Public uploads and their metadata become visible according to the selected YouTube publication settings; Google and YouTube process them under their own policies.

Revocation and deletion

Revoke the uploader’s access using Google Account connections. The owner can remove local authorization files and upload receipts from the computer. Revoking access or deleting local files does not delete videos already on YouTube; manage those videos in YouTube Studio. Contact xikangsong@orenixai.com for questions or assistance.

Information website

These static information pages contain no analytics scripts, sign-in form or video upload form. The hosting provider may process ordinary web request logs to serve the pages.

Google API data use

Our use of Google API data follows the Google API Services User Data Policy, including its Limited Use requirements. See also Google’s Privacy Policy.
