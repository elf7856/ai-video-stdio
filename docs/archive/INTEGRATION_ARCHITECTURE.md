## 🔄 集成策略

### 方案A: 微前端集成 (推荐)
```javascript
// Video Creator 主应用中嵌入 OpenCut
const openCutUrl = `http://localhost:3000/editor?token=${jwt}&project=${projectId}`;
<iframe src={openCutUrl} width="100%" height="100%" />
```

**优势:**
- 保持两个系统独立性
- OpenCut功能完整保留
- 开发工作量最小
- 易于维护和升级

## 🛠️ 技术栈确定

### 后端服务
- **框架**: FastAPI (已有)
- **数据库**: PostgreSQL + Redis
- **认证**: JWT + OAuth2
- **文件存储**: 阿里云OSS/腾讯云COS
- **容器**: Docker + Docker Compose

### 前端集成
- **主框架**: Next.js (OpenCut已有)
- **状态管理**: Zustand (OpenCut已有) 
- **通信**: Fetch API + WebSocket
- **UI组件**: Radix UI (OpenCut已有)

### 部署架构
```
├── nginx (反向代理)
│   ├── video-creator:8000 (Python/FastAPI)
│   └── opencut:3000 (Node.js/Next.js)
├── postgresql:5432 (数据库)
├── redis:6379 (缓存)
└── 云存储 (静态资源)
```
