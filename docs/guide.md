# AI视频创作平台综合指南

本文档是AI视频创作平台的综合指南，涵盖了平台的核心功能、系统架构设计、安装与部署方法。

---

## 1. 功能详解 (AI工具箱)

本平台集成了一系列强大的AI功能，形成一个多功能的“AI工具箱”，为上层的“AI导演”系统提供能力支持，也可以通过API独立调用。

### 1.1. 视频处理与分析

#### 视频下载
- **多平台支持**: 可从YouTube、Bilibili、TikTok、Instagram、Twitter等主流平台下载视频。
- **智能识别**: 自动识别视频平台并选择最佳下载策略。
- **信息获取**: 支持在不下载视频文件的情况下，预先获取视频的标题、时长、分辨率等元信息。

#### 视频内容分析
- **AI摘要与分析**: 使用大语言模型（LLM）深度分析视频内容，自动生成摘要、提炼核心主题、识别情感基调。
- **关键帧提取**: 智能提取视频中的关键帧画面，用于后续的图像分析或作为视频封面。
- **标签生成**: 根据视频内容自动生成相关的标签和分类，便于内容管理和检索。
- **语音转文字 (ASR)**: 集成`Whisper`等ASR服务，可将视频中的语音转换为带时间戳的文字稿，为内容分析和字幕生成提供基础。

### 1.2. AI图像生成

- **多API支持**: 统一封装了`DALL-E`, `Stability AI`, `Replicate`, `Leonardo AI`等多种图像生成API。
- **故障转移**: 当默认的API提供商生成失败时，系统会自动切换到其他可用的提供商进行重试，保证生成成功率。
- **本地模型支持**: 支持使用本地部署的`Stable Diffusion`模型进行图像生成，无需依赖外部API。
- **风格预设**: 内置多种艺术风格（如写实、动漫、油画、赛博朋克等），用户可通过简单指令应用复杂风格。
- **智能Prompt生成**: 可根据用户的简单需求，使用LLM自动生成更详细、更专业的图像生成Prompt。

### 1.3. TTS语音合成

- **多引擎支持**: 统一封装了`Edge TTS`和`ElevenLabs`等多种语音合成引擎。
- **免费优先与备用方案**:
    - **优先使用 `Edge TTS`**: 这是一个免费且效果优秀的服务。
    - **备用系统TTS**: 如果`Edge TTS`不可用，系统会自动调用操作系统内置的TTS（如macOS的`say`命令），确保功能可用。
- **多语言与多发音人**: 提供多种语言（中、英）和多种风格（男女声、不同情感）的发音人供选择。
- **语音参数调整**: 支持对生成的语音进行语速、音调、音量的精细化控制。

### 1.4. 自然语言编辑

- **指令理解**: 通过LLM分析用户输入的自然语言编辑指令（如“在视频开头加一个标题”）。
- **内容自动生成**: 根据分析后的指令，自动调用图像或音频生成服务来创建所需素材。
- **智能合成**: 将AI生成的内容（如标题图像、旁白）智能地插入或替换到视频的指定位置。

## 2. 系统架构设计

### 2.1. 核心理念

平台的核心目标是**将用户的文字稿件（Script）通过端到端的自动化流程，转换为一段包含多个镜头（Shots）的完整视频**。

为此，我们设计了“AI导演”系统，它模仿人类导演的工作流程，负责从内容理解到最终成片的全部决策和调度。

### 2.2. 整体架构

系统采用分层架构，确保各模块的高内聚和低耦合。

```
┌─────────────────────────────────────────────────────────┐
│                 用户界面层 (Frontend)                     │
├─────────────────────────────────────────────────────────┤
│ • 脚本输入、参数配置、进度展示、结果预览                     │
└─────────────────────────────────────────────────────────┘
                           │ (REST API & WebSocket)
┌─────────────────────────────────────────────────────────┐
│                 应用与API层 (FastAPI)                     │
├─────────────────────────────────────────────────────────┤
│ • API接口 (`/api/v1/...`)                               │
│ • 业务逻辑、用户管理、项目管理                           │
└─────────────────────────────────────────────────────────┘
                           │
┌─────────────────────────────────────────────────────────┐
│                 核心服务层 (Services)                     │
├─────────────────────────────────────────────────────────┤
│ ┌─────────────────┐ ┌─────────────────┐ ┌─────────────────┐ │
│ │   AI导演系统    │ │    AI工具箱     │ │    基础服务     │ │
│ │ (Orchestrator)  │ │  (Capabilities) │ │ (Infrastructure)│ │
│ └─────────────────┘ └─────────────────┘ └─────────────────┘ │
└─────────────────────────────────────────────────────────┘
                           │
┌─────────────────────────────────────────────────────────┐
│                 数据与存储层 (Data)                       │
├─────────────────────────────────────────────────────────┤
│ • 数据库 (PostgreSQL): 项目元数据、用户信息                │
│ • 文件系统/云存储: 视频、图片、音频等媒体文件              │
└─────────────────────────────────────────────────────────┘
```

### 2.3. AI导演系统 (Director System)

“AI导演”是整个平台的大脑，其主要组件位于 `app/services/director/` 目录下：

- **`AIDirectorController` (主控制器)**: 接收用户请求，完整协调整个视频创作流程。
- **`ContentAnalyzer` (内容分析器)**: 使用LLM分析和理解用户输入的脚本，并将其分解为逻辑片段。
- **`ShotPlanner` (分镜规划器)**: 为每个内容片段设计镜头（Shot），并生成专业的视频生成Prompt。
- **`TimingAllocator` (时长分配器)**: 为每个镜头精确分配3-15秒的播放时间，并优化视频节奏。
- **`APIOrchestrator` (API协调器)**: 管理所有外部AI视频生成API，智能选择并并发执行生成任务。
- **`ProjectManager` (项目管理器)**: 创建和管理标准化的项目目录结构及所有元数据。
- **`ProgressTracker` (进度追踪器)**: 实时监控创作流程的每个阶段，并通过WebSocket报告进度。
- **`QualityController` (质量控制器)**: 对AI生成的视频片段进行质量评估和风格一致性检查。

### 2.4. 标准化输出结构

所有项目产物都存放在一个标准化的目录结构中，确保了清晰性和可追溯性。

```
outputs/
└── projects/
    └── [project_id]/
        ├── 📹 raw_clips/              # AI生成的原始视频片段
        ├── 🎬 final_video_40s.mp4     # 最终合成的视频
        ├── 📊 metadata/               # 项目元数据
        │   ├── project_info.json
        │   ├── shot_plan.json
        │   └── generation_stats.json
        └── 📋 logs/                   # 详细日志
```

## 3. 安装与部署

### 3.1. 环境要求

- **软件**: Python 3.11+, FFmpeg, Docker (推荐), Git。
- **硬件**: 推荐8核+ CPU, 16GB+ RAM, NVIDIA GPU (用于本地图像生成), 100GB+ SSD。

### 3.2. 本地开发环境设置

#### 步骤1：克隆项目
```bash
git clone <repository-url>
cd video_creator_platform
```

#### 步骤2：安装依赖
建议使用虚拟环境。
```bash
python -m venv .venv
source .venv/bin/activate  # macOS/Linux
# .venv\Scripts\activate  # Windows

pip install -r requirements.txt
```

#### 步骤3：配置环境变量
1.  复制示例文件：`cp .env.example .env`
2.  编辑 `.env` 文件，填入必要的API密钥（建议优先配置 `OPENAI_API_KEY`）。

#### 步骤4：启动开发服务器
```bash
python -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```
- **API文档**: `http://localhost:8000/docs`
- **健康检查**: `http://localhost:8000/health`

### 3.3. 生产环境部署 (Docker)

我们强烈建议使用Docker和Docker Compose进行生产环境部署。

1.  确保Docker已安装。
2.  根据实际情况调整 `docker-compose.yml` 文件。
3.  在项目根目录下执行：
    ```bash
    docker-compose up --build -d
    ```

### 3.4. 常用命令

- **运行测试**: `pytest tests/ -v`
- **检查API状态**: `python check_api_status.py`
