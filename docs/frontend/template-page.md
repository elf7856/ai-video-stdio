# 模板页面 (Template Page)

## 1. 用途

该页面是用户寻找和选择视频创作模板的入口。用户可以在此浏览所有可用的模板，并通过分类和搜索功能快速找到满足其需求的模板。

## 2. 主要功能

- **模板展示**: 以卡片网格的形式展示所有视频模板。每个卡片包含模板的预览视频/图片、标题、时长和标签。
- **分类筛选**:
    - 在页面左侧提供一个筛选栏。
    - 用户可以根据模板的类别（如“产品宣传”、“社交媒体故事”、“活动预告”）、风格（如“现代”、“复古”、“简约”）或用途进行筛选。
- **搜索功能**:
    - 在页面顶部提供一个搜索框。
    - 用户可以输入关键词来搜索模板标题或标签。
- **排序功能**:
    - 在模板列表的右上方提供排序选项。
    - 用户可以按“最新发布”、“最受欢迎”或“时长”对模板进行排序。
- **模板详情**:
    - 点击模板卡片后，可以弹出一个模态框或跳转到新的详情页，展示模板的详细信息和更大的预览窗口。
    - 提供一个“使用此模板”的按钮。

## 3. 页面布局

- **顶部**: 全局导航栏。
- **左侧**:
    - 一个可折叠的侧边栏，包含所有分类和筛选选项。
- **右侧/主内容区**:
    - 顶部是搜索框和排序选项。
    - 下方是模板卡片组成的网格布局。
    - 底部是分页控件，用于浏览更多模板。
