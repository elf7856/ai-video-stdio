# 视频生成页面 (Video Generation Page)

## 1. 用途

当用户选择一个模板后，会进入此页面。该页面是视频创作的核心环节，用户可以在这里进行个性化编辑，包括替换文本、上传自己的素材（图片、视频片段），并最终生成视频。

## 2. 主要功能

- **视频预览**:
    - 页面右侧有一个实时预览窗口，展示当前编辑效果。
    - 预览窗口下方有播放/暂停/进度条等基本控制。
- **编辑表单**:
    - 页面左侧是编辑区域，根据所选模板动态生成。
    - **场景/镜头列表**: 如果模板包含多个场景，这里会列出所有场景，用户可以点击切换进行编辑。
    - **文本编辑**: 每个场景中的可编辑文本都会以输入框的形式出现，用户可以直接修改。
    - **素材上传/替换**:
        - 每个可替换的图片或视频片段都会有一个占位符和“上传”或“替换”按钮。
        - 用户可以从本地上传新素材，或从“用户内容管理”中选择已上传的素材。
- **配音/背景音乐**:
    - 提供选项让用户选择背景音乐（BGM）。
    - 提供文本转语音（TTS）功能，用户输入文字即可生成配音。
- **操作按钮**:
    - **生成视频**: 点击后开始后台渲染视频。页面应显示进度条或状态提示。
    - **保存草稿**: 用户可以随时保存当前的编辑状态，以便稍后继续。
    - **预览完整视频**: 在生成最终视频前，提供一个低分辨率的快速预览功能。

## 3. 页面布局

- **顶部**: 全局导航栏，可能包含项目名称和保存状态。
- **左侧**:
    - 一个滚动区域，包含所有可编辑的选项。
    - 按场景（Scene）或元素（Element）组织成折叠面板（Accordion）。
    - 每个面板里是对应的文本框、上传按钮等。
- **右侧/主内容区**:
    - 顶部是视频预览窗口。
    - 下方是时间轴（可选，高级功能），用于展示每个元素在视频中的时间分布。
- **底部/右上角**:
    - 包含“保存草稿”和“生成视频”等主要操作按钮。
